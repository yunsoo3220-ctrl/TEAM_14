# 리눅스 · 맥 지원 (변경 정리)

Windows 전용이던 서버를 **리눅스와 macOS 에서도 그대로 빌드·실행**할 수 있게 바꿨다.
목표는 리눅스 노트북을 계속 켜 두고 서버로 쓰는 것이다.
같은 소스 하나로 세 OS 를 모두 지원한다. Windows 에서도 `make` 로 `server.exe` 를 빌드할 수 있지만,
Windows 전용 실행 스크립트(`.bat`, `.ps1`)는 지웠다 (5장).

실행 방법은 [서버실행방법-리눅스.md](서버실행방법-리눅스.md) 에 따로 정리했다.

---

## 1. 무엇이 바뀌었나

| 영역 | 전 (Windows 전용) | 후 (Windows / 리눅스 / 맥) |
| --- | --- | --- |
| HTTP 서버 소켓 | Winsock2 | Windows 는 Winsock2, 리눅스·맥은 BSD 소켓 (`src/http.c` 안에서 `#ifdef`) |
| 바깥으로 나가는 HTTPS | WinHTTP (공지 수집·Claude API·임베딩, 3곳에 따로 구현) | **libcurl** 하나 (`src/net.c`). 메일 발송에 이미 쓰던 라이브러리 |
| 잠금 | `CRITICAL_SECTION` | `Mutex` (Windows: CRITICAL_SECTION, POSIX: 재진입 가능 pthread 뮤텍스) |
| 스레드 | `CreateThread` | `thread_start()` (Windows: CreateThread, POSIX: detached pthread) |
| 원자 연산 | `InterlockedCompareExchange` / `InterlockedExchange` | `atomic_cas()` / `atomic_swap()` (gcc·clang 내장 함수) |
| 대기·시간 | `Sleep`, `GetTickCount64`, `localtime_s`, `gmtime_s` | `sleep_ms`, `tick_ms`, `local_time`, `utc_time` |
| 난수 | `rand_s` | `os_random()` (Windows: rand_s, POSIX: `/dev/urandom`) |
| 대소문자 무시 비교 | `_strnicmp`, `_stricmp` | `strncasecmp`, `str_ieq` |
| 빌드 | MSYS2 경로 고정 | OS 를 알아서 판별. 리눅스·맥은 `mariadb_config`/`mysql_config`, `curl-config` 로 경로를 찾는다 |
| 실행 스크립트 | PowerShell (`.ps1`, `.bat`) | bash 스크립트 (`.sh`). `.ps1`·`.bat` 은 지움 |
| 상시 운영 | 없음 | systemd 서비스 (부팅 시 자동 시작, 죽으면 재시작, 매일 공지 수집) |

**Windows 빌드도 이제 WinHTTP 대신 libcurl 을 쓴다.** 링크 옵션에서 `-lwinhttp` 가 빠졌다.
MSYS2 의 `mingw-w64-ucrt-x86_64-curl` 은 원래 메일 때문에 필요했으므로 새로 설치할 것은 없다.

## 2. 바뀐 파일

### 새 파일

| 파일 | 내용 |
| --- | --- |
| `src/platform.h`, `src/platform.c` | OS 차이를 감추는 얇은 층. 잠금, 스레드, 시간, 난수, 원자 연산, 시작 설정(`platform_init`) |
| `src/net.h`, `src/net.c` | libcurl HTTP(S) 클라이언트 `net_request()` 와 전역 초기화 `net_init()` |

| `scripts/run-server.sh` | env 파일을 읽고 `./server` 를 실행 (일회성 명령 `--add-admin`, `--crawl`, `--test-mail` 등에도 사용) |

| `서버켜기.sh`, `서버끄기.sh` | 서버 켜기·끄기 (지운 `서버켜기.bat`, `서버끄기.bat` 을 대신함) |
| `서버실행방법-리눅스.md` | 리눅스·맥 실행 안내 |
| `.gitattributes` | `.sh` 파일은 항상 LF 줄바꿈으로 받게 함 |

### 고친 파일

| 파일 | 바뀐 점 |

| `src/db.c`, `src/db.h` | `CRITICAL_SECTION` → `Mutex`. MySQL 8 클라이언트에 `my_bool` 이 없을 때를 대비한 정의 추가 |
| `src/ml.c` | 잠금·원자 연산·시간 함수 교체. `_stricmp` → `str_ieq` |
| `src/str.c` | `rand_s` → `os_random`, `localtime_s` → `local_time` |
| `src/api_ml.c` | `localtime_s` → `local_time` |
| `src/main.c` | `SetConsoleOutputCP` → `platform_init()`, 시작할 때 `net_init()`. **환경변수 `SKU_DB_USER`, `SKU_DB_HOST` 를 새로 읽음**. 도움말·오류 문구가 지운 `.ps1` 대신 `.sh` 스크립트를 안내 |
| `src/mailer.h`, `smtp.env.example` | 주석이 `start-server.ps1` 대신 `run-server.sh` 를 가리킴 |
| `src/http.h` | 주석 |
| `Makefile` | Windows / 리눅스·맥 분기. `make run` 은 리눅스·맥에서 8080 포트 |
| `scripts/make_admin.py` | 리눅스·맥에서는 PATH 의 `mysql` 을 기본으로 |
| `.gitignore` | 리눅스 실행 파일 `/server`, `ai.env` 추가 |
| `README2.md` | 리눅스 안내 링크, 낡은 설명(WinHTTP 등) 수정. 주소 연결·실행·임베딩 설치·메일 시험·파일 구조 절에서 `.ps1`·`.bat` 을 `.sh` 스크립트로 바꿈 |
| `서버실행방법-리눅스.md` | 지운 `서버실행방법.md` 에 있던 **인증 메일(Gmail 앱 비밀번호) 설정 방법**을 이 문서로 옮김 |

## 3. 설계 메모

- **OS 차이는 두 곳에만 둔다.** `platform.c` (잠금·스레드·시간·난수)와 `http.c` 위쪽 (소켓).
  나머지 코드에는 `#ifdef _WIN32` 가 없다. 새 코드에서 Windows API 를 직접 부르지 말고 `platform.h` 함수를 쓴다.
- **`Mutex` 는 재진입 가능해야 한다.** `db_lock()` 으로 잠근 채 `db_exec()` 를 부르는 코드가 있어서,
  POSIX 쪽은 `PTHREAD_MUTEX_RECURSIVE` 로 만든다 (Windows 의 CRITICAL_SECTION 과 같은 성질).
- **스레드 스택은 2MB 로 고정.** macOS 의 보조 스레드 기본값(512KB)은 Windows(1MB)보다 작아서 넉넉히 맞췄다.
- **SIGPIPE 를 무시한다.** 리눅스에서는 브라우저가 먼저 끊은 소켓에 `send` 하면 프로세스가 통째로 죽는다.
- **WinHTTP 대신 libcurl 로 통일한 이유:** 같은 HTTP 요청 코드가 세 파일에 복사돼 있었고,
  libcurl 은 이미 메일 때문에 링크하고 있었다. 시간 제한은 기존 값에 맞췄다 (Claude API 접속 15초·전체 210초,
  공지 수집 접속 20초·전체 60초, 임베딩 접속 2초). 프록시는 환경변수(`https_proxy`)를 따른다.
- **리눅스의 DB 계정:** Ubuntu 의 MySQL root 는 비밀번호 대신 OS 계정으로 로그인(`sudo mysql`)하므로
  서버가 root 로 접속할 수 없다. `setup-linux.sh` 가 `sku` 계정을 만들고 32자 난수 비밀번호를 `db.env` (권한 600)에 저장한다.
  접속은 `SKU_DB_HOST=localhost` 로 **유닉스 소켓**을 쓴다. MySQL 8 의 기본 인증이 암호화되지 않은 TCP 로 처음 로그인할 때
  TLS 를 요구할 수 있어서다.
- **systemd 서비스는 root 가 아니라 사용자 계정으로 돈다.** 80 포트를 열 권한(`CAP_NET_BIND_SERVICE`) 하나만 준다.
  로그는 `journalctl -u sku14` 로 본다.
- **SQL 은 그대로다.** MySQL 전용 문법이 없어서 Debian 처럼 MariaDB 서버만 있는 배포판에서도 동작한다.

## 4. 확인 상태

| 항목 | 결과 |
| --- | --- |
| Windows 빌드 (MSYS2 gcc, `-Wall -Wextra`) | ✅ 경고 없이 빌드 |
| libcurl 클라이언트 (Windows) | ✅ 학교 홈페이지 HTTPS 200 응답, 꺼진 로컬 포트는 바로 실패 |
| 난수·로그 시각 (Windows) | ✅ |
| `env.sh` 파싱 | ✅ CRLF 파일, 예시 값 무시, 앱 비밀번호 공백 제거, 허용하지 않은 키 무시 |
| 셸 스크립트 문법 (`bash -n`) | ✅ 7개 모두 |
| **리눅스·맥 실제 빌드·실행** | ⚠️ **아직 안 함.** 이 PC 에 WSL·Docker 가 없어 코드 검토만 했다 |
| 남은 Win32 호출 검사 | ✅ `#ifdef _WIN32` 밖에는 없음 (주석 제외) |

리눅스 노트북에서 처음 `scripts/setup-linux.sh` 를 돌릴 때 빌드 오류가 나면 이 문서와 함께 알려 주면 된다.

## 5. 지운 파일

리눅스 노트북에서 운영하므로 Windows 전용 실행 스크립트와 정리가 끝난 메모 파일을 지웠다.
모두 git 기록에 남아 있으므로 필요하면 되살릴 수 있다 (`git checkout <지우기 전 커밋> -- <파일>`).

| 지운 파일 | 무엇이었나 | 대신 쓰는 것 |
| --- | --- | --- |
| `서버켜기.bat`, `서버끄기.bat` | 더블클릭으로 서버 켜기·끄기 (Windows) | `서버켜기.sh`, `서버끄기.sh` |
| `scripts/launch.ps1` | 위 두 `.bat` 이 부르던 스크립트. 관리자 권한 요청, `db.env` 저장, hosts 등록, 브라우저 열기 | `서버켜기.sh` + `scripts/start-server.sh` |
| `scripts/start-server.ps1` | 서버·임베딩 서비스 백그라운드 실행/중지, 로그를 `logs/` 에 | `scripts/start-server.sh` (계속 켜 둘 때는 `scripts/install-service.sh`) |
| `scripts/smtp-env.ps1` | `smtp.env` 를 읽어 환경변수로 올림 | `scripts/env.sh` |
| `scripts/send-test-mail.ps1` | SMTP 시험 메일 발송 | `scripts/run-server.sh --test-mail 주소` |
| `scripts/setup-domain.ps1` | Windows hosts 에 `www.sku14.com` 등록/제거 | `scripts/setup-linux.sh --hosts` |
| `서버실행방법.md` | Windows 더블클릭 실행 안내, 인증 메일 설정, 문제 해결 | `서버실행방법-리눅스.md` (메일 설정 내용은 이쪽으로 옮김) |
| `README.md` | 그룹 스터디 기능을 추가할 때 쓴 변경 정리 (화면, DB, API, 적용 방법) | 기능 설명은 `README2.md` 의 "그룹 스터디" 절, 표 정의는 `sql/12_study_groups.sql` |
| `branch.txt` | 그룹 스터디 작업 때의 git·실행 명령 메모 | 없음 (일회성 메모) |
| `공모전정리.txt` | 시스템 구조도 (브라우저 ↔ 서버 ↔ DB) | `README2.md` 의 "파일 구조"·"설계 메모" 절 |

Windows 에서 계속 돌려야 한다면 `make` 로 빌드한 뒤 `server.exe` 를 직접 실행하면 된다
(`$env:SKU_DB_PASS="..."; .\server.exe`). 다만 `smtp.env` 를 자동으로 읽어 주는 스크립트는 이제 없으므로
`SKU_SMTP_*` 환경변수를 직접 설정해야 한다.
