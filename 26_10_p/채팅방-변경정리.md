# 채팅방 · 모집글 팀 (변경 정리, 2026-10-14)

팀원 모집 팀, 그룹 스터디, 멘토링에 들어간 사람끼리 **채팅방**에서 이야기할 수 있게 했다.
모임에 들어가면 그 모임의 채팅방에 바로 들어갈 수 있다. 방을 따로 만들 필요는 없다.

| 한 일 | 핵심 |
| --- | --- |
| 1. 채팅방 메뉴 | 사이드바 **채팅방** (`#/chats`), 안 읽은 메시지 배지. 최근 대화가 있는 방이 위로 |
| 2. 채팅방 화면 | 말풍선, 날짜 구분선, Enter 보내기 · Shift+Enter 줄바꿈, 내 메시지 삭제, 이전 대화 더 보기 |
| 3. 채팅방으로 이동 버튼 | "내가 속한 스터디/멘토링" 목록 카드, 상세 화면, 모집글 카드·상세 |
| 4. 모집글 팀 | 모집글에 **팀원** 개념을 새로 만듦. 글쓴이가 댓글 단 회원을 [팀원으로 받기] |

---

## 1. 누가 어느 방에 들어가나

| 방 | 멤버 |
| --- | --- |
| 그룹 스터디 · 멘토링 | 그 모임의 멤버 (`study_members`) — 참여하기·방장이 추가 |
| 팀원 모집 | 글쓴이 + 글쓴이가 받은 팀원 (`recruit_members`, 새 표) |

- 멤버가 아니면 들어갈 수 없다 (관리자도 멤버가 아니면 못 본다). 나가거나 내보내지면 바로 못 들어간다.
- 모임이 지워지면 메시지도 자동 정리가 지운다.

## 2. 모집글 팀 (새로 생긴 개념)

전에는 모집글에 멤버가 없어서(참여 = 댓글) 채팅방을 붙일 수 없었다. 그래서 팀을 만들었다.

- 모집글 상세에 **팀** 칸: 글쓴이 + 팀원 목록
- 글쓴이(·관리자)에게는 아직 팀이 아닌 댓글 작성자 옆에 **[팀원으로 받기]** 버튼
  - 받은 회원의 알림함에 🤝 "팀원으로 받아 주었습니다" → 누르면 팀 채팅방으로
- 글쓴이는 [내보내기], 팀원은 [팀 나가기]. 팀원은 20명까지
- 참여 권유 알림에서 [참여하기]를 누르면 이제 **팀원도 된다** (참여 댓글도 그대로 남긴다)
- 팀원 모집 목록 "상태"에 **내가 속한 팀** 보기 추가 (마감한 글 포함)
- **자동 정리 변경**: 마감한 모집글은 원래 1시간 안에 지워졌다. 이제 **팀원이 있는 글은 쓴 날부터 90일까지 남긴다** (팀 채팅방 때문에). 팀원이 없는 글은 예전처럼 지운다.

## 3. 동작 방식

- 실시간 연결(웹소켓) 대신 채팅방 화면이 **3초마다** 새 메시지만 받아 간다 (`?after=마지막id`). 탭이 가려져 있으면 쉬고, 다른 화면으로 가면 멈춘다.
- 안 읽은 수: 방마다 "어디까지 읽었는지"(`chat_reads`)를 저장하고 그보다 새로운 남의 메시지를 센다.
- 메시지 1000자까지, 도배 방지로 1분에 30개까지. 정지된 회원은 읽기만 가능 (기존 정지 차단이 그대로 적용).
- 한글 입력 중 Enter(글자 확정)는 보내지 않는다.

## 4. API

| 메서드 | 주소 | 설명 |
| --- | --- | --- |
| GET | `/api/chats` | 내 채팅방 목록 + 마지막 메시지 · 안 읽은 수 |
| GET | `/api/chats/{recruit\|study}/{id}` | 방 정보·멤버 + 최근 100개 (`?after=` 새 메시지, `?before=` 이전 대화) |
| POST | `/api/chats/{recruit\|study}/{id}/messages` | 보내기 `{body}` |
| DELETE | `/api/chat-messages/{id}` | 내 메시지 지우기 |
| POST | `/api/recruits/{id}/members` | 팀원으로 받기 `{user_id}` (글쓴이·관리자) |
| DELETE | `/api/recruits/{id}/members/{uid}` | 내보내기 (글쓴이·관리자) / 팀 나가기 (본인) |

`/api/me` 에 `unread_chats` (사이드바 배지), 모집글 응답에 `in_team`·`team_count`, 상세에 `team` 이 추가됐다.
