# 서버 실행 방법

명령어 없이 **더블클릭만으로** 서버를 켜고 끄는 방법을 정리한 문서다.
빌드(`make`)와 DB 준비(`make db`)는 이미 끝났다고 가정한다. 처음이라면 [README2.md](README2.md) 의 1~3장을 먼저 따른다.

---

## 한눈에 보기

| 파일 | 하는 일 |
| --- | --- |
| `서버켜기.bat` | 서버를 켜고 브라우저로 <http://www.sku14.com> 을 연다 |
| `서버끄기.bat` | 떠 있는 서버를 끈다 |
| `scripts\launch.ps1` | 두 bat 파일이 부르는 스크립트 (직접 실행할 필요 없음) |

두 bat 파일은 프로젝트 폴더(`26_10_p`) 바로 아래에 있다.

## 처음 한 번만 할 일: 인증 메일 설정

회원가입은 학교 메일(`@skuniv.ac.kr`)로 인증번호를 받아야 한다.
그 메일을 **보내는** 계정(Gmail)을 `smtp.env` 에 적어 둔다.

```
[smtp.env 의 Gmail]  ──인증번호──▶  [가입하는 학생의 @skuniv.ac.kr]
   보내는 사람 (1개)                    받는 사람 (가입자마다 다름)
```

1. 보낼 Gmail 계정에서 **2단계 인증**을 켠다.
2. <https://myaccount.google.com/apppasswords> 에서 **앱 비밀번호 16자리**를 만든다.
3. `smtp.env.example` 을 `smtp.env` 로 복사하고 위쪽 네 줄을 채운 뒤 **저장(Ctrl+S)** 한다.

   ```
   SKU_SMTP_URL=smtps://smtp.gmail.com:465
   SKU_SMTP_USER=보낼계정@gmail.com
   SKU_SMTP_PASS=앱비밀번호16자리
   SKU_SMTP_FROM=보낼계정@gmail.com
   ```

   - `SKU_SMTP_PASS` 는 Gmail 로그인 비밀번호가 **아니라** 앱 비밀번호다.
4. (선택) 설정이 맞는지 시험 메일을 보내 본다.

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\send-test-mail.ps1 -To 받을주소@gmail.com
   ```

`smtp.env` 는 비밀번호가 들어 있어 git 에 올라가지 않는다 (`.gitignore`).

## 서버 켜기

**`서버켜기.bat` 을 더블클릭한다.**

1. "이 앱이 디바이스를 변경하도록 허용하시겠어요?" 창이 뜨면 **예**.
2. **처음 한 번만** MySQL root 비밀번호를 묻는다. 입력하면 `db.env` 에 저장되고 다음부터는 묻지 않는다.
3. `www.sku14.com` 이 이 PC 에 연결돼 있지 않으면 자동으로 hosts 파일에 등록한다.
4. 이미 떠 있는 서버가 있으면 내리고 새로 띄운다. 이때 `smtp.env` 의 메일 설정을 읽는다.
5. 브라우저가 <http://www.sku14.com> 으로 열린다.

창에 아래와 같이 나오면 정상이다.

```
인증 메일 발송: smtps://smtp.gmail.com:465 (보낼계정@gmail.com)
서버 실행 중 (PID ...., 포트 80)
```

`smtp.env 가 없어 회원가입 인증 메일을 보낼 수 없습니다` 가 노랗게 뜨면 메일 설정이 비어 있는 것이다.
위의 "인증 메일 설정"을 다시 확인한다.

## 서버 끄기

**`서버끄기.bat` 을 더블클릭**하고 관리자 권한 창에서 **예**를 누른다.

---

## 문제 해결

| 증상 | 해결 |
| --- | --- |
| "DB 비밀번호가 틀렸습니다" | 저장된 비밀번호는 자동으로 지워진다. `서버켜기.bat` 을 다시 실행해 올바른 비밀번호를 넣는다. |
| "서버가 바로 종료되었습니다" | 창에 찍힌 로그를 본다. MySQL 이 꺼져 있으면 관리자 PowerShell 에서 `net start MySQL84`. |
| 가입할 때 "메일 서버가 설정되지 않았습니다" | `smtp.env` 를 채우고 저장했는지 확인한 뒤 `서버켜기.bat` 을 다시 실행한다. |
| 인증번호 메일이 안 온다 | 학교 메일함의 **스팸함**을 확인한다. 그래도 없으면 `logs\server.err.log` 마지막 줄을 본다. `535 ... not accepted` 는 앱 비밀번호가 틀린 것이다. |
| 관리자 권한 창에서 "아니요"를 눌렀다 | 80 포트와 hosts 파일을 쓰려면 관리자 권한이 필요하다. 다시 실행해 **예**를 누른다. |

로그 위치: `logs\server.err.log` (서버), `logs\embed.err.log` (임베딩 서비스)

## 저장되는 파일 (git 에 올라가지 않음)

| 파일 | 내용 |
| --- | --- |
| `smtp.env` | 인증 메일을 보낼 Gmail 계정과 앱 비밀번호 |
| `db.env` | MySQL root 비밀번호 (`서버켜기.bat` 이 처음 실행할 때 만든다) |

DB 비밀번호를 바꿨다면 `db.env` 를 지우고 `서버켜기.bat` 을 다시 실행하면 새로 묻는다.

## 다른 사람도 접속하게 하려면

`www.sku14.com` 연결은 **이 PC 안에서만** 유효하다. 다른 사람이 들어오게 하려면:

- **같은 와이파이** — 서버를 `--bind-all` 로 띄우고 방화벽에서 80 포트를 연 뒤,
  다른 기기에서 `http://<이 PC 의 IP>` 로 접속한다 (`ipconfig` 로 IP 확인).
- **인터넷 어디서나 (임시)** — Cloudflare Tunnel: `cloudflared tunnel --url http://localhost:80`
- **정식 운영** — `sku14.com` 도메인을 사서 A 레코드를 서버 공인 IP 로 지정한다.

메일 설정은 그대로 두면 된다. 누가 가입하든 그 사람의 학교 메일로 인증번호가 간다.
